# Baymax Mobile

This project contains Baymax mobile implementations. 

## Baymax for ios
The `ios` dir is an ios client (which is an implementation of a remote protocol to access the baymax agent) which connects back to your baymax agent from anywhere, via a tunnel.


## Roadmap and help wanted

### Android client 

A `android` client is planned to effectively be a port of the `ios` project, a client to a remote baymax, and will be available on google play store eventually. This is a very early start on this project.

### ACP support

We plan to migrate the client to use a http/remote version of the ACP (agent client protocol) which will allow the baymax ios client to work with a variety of agents.

### Push messaging

Push messaging would be very useful for long running agentic workloads, this is an area to explore for how this can work for a variety of (open source) backends.
