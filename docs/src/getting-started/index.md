# Getting Started

Sim is a fast, collaborative code editor with native agent tools, project navigation, terminal workflows, and configurable AI providers. This section gives new users the shortest reliable path from installation to a useful first session.

## Start Here

1. Install Sim for your platform in [Installation](./installation.md).
2. Open a project from the command line or the welcome screen.
3. Learn the core commands in [Quickstart](./quickstart.md).
4. Configure providers, extensions, and editor preferences in [Configuration](./configuration.md).

## First Project

Open a folder from the command line:

```sh
sim ~/projects/my-app
```

Or use **File > Open Folder** from inside Sim. The command palette is the fastest way to find actions after the project opens:

| Action | macOS | Linux/Windows |
| --- | --- | --- |
| Command palette | `Cmd+Shift+P` | `Ctrl+Shift+P` |
| Go to file | `Cmd+P` | `Ctrl+P` |
| Find in project | `Cmd+Shift+F` | `Ctrl+Shift+F` |
| Toggle terminal | `` Ctrl+` `` | `` Ctrl+` `` |
| Open settings | `Cmd+,` | `Ctrl+,` |
