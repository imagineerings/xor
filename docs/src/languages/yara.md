# Yara

`Yara` language support in Baymax is provided by the [Yara language extension](https://github.com/egibs/yara.baymax). Please report issues to [https://github.com/egibs/yara.baymax/issues](https://github.com/egibs/yara.baymax/issues).

- Tree-sitter: [egibs/tree-sitter-yara](https://github.com/egibs/tree-sitter-yara)
- Language Server: [avast/yls](https://github.com/avast/yls)
