# Yara

`Yara` language support in Sim is provided by the [Yara language extension](https://github.com/egibs/yara.sim). Please report issues to [https://github.com/egibs/yara.sim/issues](https://github.com/egibs/yara.sim/issues).

- Tree-sitter: [egibs/tree-sitter-yara](https://github.com/egibs/tree-sitter-yara)
- Language Server: [avast/yls](https://github.com/avast/yls)
