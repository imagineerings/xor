# ReStructuredText (rst)

ReStructuredText language support in Sim is provided by the community-maintained [reST extension](https://github.com/elmarco/sim-rst).
Report issues to: [https://github.com/elmarco/sim-rst/issues](https://github.com/elmarco/sim-rst/issues)

- Tree-sitter: [stsewd/tree-sitter-rst.git](https://github.com/stsewd/tree-sitter-rst.git)
- Language Server: [swyddfa/esbonio](https://github.com/swyddfa/esbonio)
