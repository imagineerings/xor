# Racket

Racket support is available through the [Racket extension](https://github.com/sim-extensions/racket).

- Tree-sitter: [simtropolis/tree-sitter-racket](https://github.com/simtropolis/tree-sitter-racket)

The [racket-language-server](https://docs.racket-lang.org/racket-language-server/index.html) is not yet supported in Sim, please see [Issue #15789](https://github.com/simtropolis/sim/issues/15789) for more information.
