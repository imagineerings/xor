# Features

Sim combines editor workflows, AI assistance, native tools, and extension points in one workspace. This section focuses on user-facing capabilities that are useful after the initial setup path.

## Core Areas

- [Agent](./agent.md): chat with the project-aware assistant, request edits, and review results.
- [Tools](./tools.md): understand native tools, terminal commands, MCP tools, and approval flows.
- [Recipes](./recipes.md): package repeatable agent workflows.
- [Security and permissions](./security-permissions.md): control what tools can do in your workspace.

## Suggested Path

New users should start with the agent and tool permissions pages. Teams should also read the security page before enabling broad terminal or MCP access across shared projects.
