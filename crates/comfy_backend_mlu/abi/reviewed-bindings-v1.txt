The exact public packages were fetched from the URLs pinned in the normative
native-backend ABI catalog. The nested CNRT package, direct CNNL package, and
both headers matched the pre-existing package and header digests before these
facts were recorded. Vendor headers and runtime binaries are not redistributed.

The production error adapter maps cnrtErrorNoMem and
CNNL_STATUS_ALLOC_FAILED to typed out-of-memory. It maps cnrtErrorNoDevice to
typed device loss only for a CNRT operation; every reviewed call reselects its
device before touching a resource. Other CNRT driver failures and all ambiguous
CNNL execution failures remain typed vendor-call failures. Numeric values are
classified in their CNRT or CNNL operation domain so a coincident value in the
other library cannot acquire the wrong meaning.

Development verification: compile abi/verify-bindings.c against the exact
CNRT/CNNL headers. The verifier checks versions, status sizes, and all five
status constants. The Rust manifest validator independently rejects missing,
reordered, renamed, or changed status rows.
