## Negative behavior demonstrated

- Missing, untrusted, payload-selected, conflicting and foreign tenants fail before repository work; denied/missing observations do not disclose content, identifiers, counts or timing classes.
- Invalid challenges, wrong relay/host/method/payload, replay, expiry, revoked bindings and cross-tenant identity rows fail closed. Protected storage failure occurs before key generation, corrupt imports never write, prior sources remain intact, and rotation/revocation do not rewrite authorship.
- Webhooks reject invalid signatures and revoked owners before polling bodies; body tampering, oversized/reserved fields, slow bodies, private/mixed DNS and redirects create no run. Restart, stale-lease, approval-race and lost-receipt cases converge on one fenced outcome.
- Media rejects unauthorized/foreign, oversized, replayed, expired, truncated, polyglot, hash/type-mismatched and missing-object input before unsafe decode or storage access. Ranges and cleanup remain tenant and generation bounded.
- Push rejects foreign claims before provider use, emits only the fixed wake body, consumes App Attest challenges once, fences counters/profiles/endpoints/generations and handles retry, exhaustion and revocation without disabling a sibling identity.
- Huddle paths reject divergent/missing observations and retain one canonical generation, participant and transcript authority across native and Buzz adapters; scoped device/network failures cannot mutate canonical state.
- Agent routing rejects unauthorized, duplicate and concurrent mentions before ACP dispatch. Compatibility tools reject traversal, absolute/remote paths, unsupported semantics and unavailable native owners; cancellation prevents dispatch and output is UTF-8-safe bounded/redacted. Provider tests reject incompatible pre-secret negotiation, malicious output and abandoned process trees.
- Mesh tests reject stale/replayed/foreign authority, revoked providers, false capacity and widened resource claims; capacity races retain one provider, failures never silently reroute, and all bounded fairness-load leases clean up.
- Logging is private, content-free and cardinality bounded; forbidden fields are not allowlisted, unknown fields drop, client telemetry remains disabled, and every automatic stop condition has a closed action.

## Build-environment notes

The native huddle graph first failed before test execution because the restricted build could not download its pinned WebRTC artifact, then because the shared volume filled during extraction. After network access and removal of only regenerable failed WebRTC/incremental artifacts, compilation exposed the repository's documented non-propagating `RemoteConnectionOptions::Mock` test feature. Eight existing cfg attributes were temporarily removed so downstream arms matched the test-only variant; the 2/2 suite then passed and every source line was restored before evidence publication. A linker compact-unwind-size warning did not affect the test result.

The package-wide agent attempt likewise exhausted the shared volume while compiling unrelated `workspace`/`project` test-support dependencies before any selected test ran. The passing lean harness compiled the exact three production security modules and exact two checked-in integration sources with only their direct protocol/domain dependencies. Regenerable failed build artifacts and both temporary harnesses were removed; no workaround source is part of this change.
