# Requirements: Agentic Game Tools

## Introduction

Sim agents should be able to edit diffusion graphs, create world generation requests, and generate/import mesh assets through typed and validated tools.

### Requirement 1: Graph Editing Tools

#### Acceptance Criteria

1.1 WHEN an agent edits a graph THEN THE system SHALL validate graph changes before applying them.

### Requirement 2: Generation Tools

#### Acceptance Criteria

2.1 WHEN an agent requests world or mesh generation THEN THE system SHALL use typed requests.
2.2 WHEN generated outputs are imported THEN THE system SHALL attach provenance.
